2. What I Built

เว็บนี้เป็นหน้า Learning Portfolio หน้าเดียวที่ทำขึ้นมาเก็บผลงานและสรุปการเรียนรู้เบื้องต้น ข้างในจะมีข้อมูลแนะนำตัว สรุปขั้นตอนการทำงาน สิ่งที่ได้เรียนรู้จากการลองเขียนเว็บจริง แล้วก็มีรูปภาพกับลิงก์องค์ประกอบต่างๆ ใส่ไว้ด้วย

ตอนเปิดไฟล์เว็บขึ้นมาดูในคอมตัวเอง กระบวนการทั้งหมดเกิดขึ้นที่ Client เพราะตัวโปรแกรมเบราว์เซอร์ในเครื่องทำหน้าที่เปิดอ่านไฟล์ HTML และ CSS จากโฟลเดอร์ในเครื่องมาแสดงผลทันที โดยไม่ได้ผ่าน Server เครื่องอื่นเลย

3. How I Built It

ขั้นตอนการทำเว็บนี้ เริ่มจากวางโครงสร้างหน้าเว็บด้วย Semantic HTML เพื่อแบ่งส่วนเนื้อหา แล้วค่อยใช้ CSS เข้ามาช่วยจัดรูปแบบ ฟอนต์ และสีสันให้ดูเป็นระเบียบ

ส่วนเครื่องมือที่ใช้เขียนโค้ดคือโปรแกรม VS Code และเปิดดูตัวอย่างการใช้แท็ก HTML/CSS ต่างๆ จากเว็บ MDN Web Docs

4. Reflection

ปัญหาและความท้าทายที่พบ: ยังสับงงเรื่อง syntax เช่น การลืมปิดแท็ก หรือระบุ path ของไฟล์ CSS และรูปภาพผิด ทำให้สไตล์ไม่ขึ้นเหมือนที่คิดไว้แก้โดยการไล่เช้กที่ละบรรทัด

สิ่งที่ได้เรียนรู้: ได้ฝึกใช้ Semantic HTML มาจัดโครงสร้างเว็บให้เป็นระเบียบ อ่านง่ายขึ้น

สิ่งที่อยากปรับปรุงในอนาคต: อยากฝึกแต่ง CSS ให้ดูสวยเป็นระเบียบมากกว่านี้

5. HTML Elements & Media

ส่วนนี้เป็นการสรุปองค์ประกอบของ HTML ที่นำมาใช้สร้างหน้าเว็บนี้

  • Semantic HTML Tags: header, nav, main, section, footer
  • Text Tags: h1, h2, p, strong, em
  • List Tags: ul, li
  • Media & Link Tags: img, a
